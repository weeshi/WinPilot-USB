# Weeshi USB Installer — دليل التحديث

## تحديث التطبيق

من الإصدار `1.1.0` يفحص التطبيق أحدث GitHub Release تلقائيًا عند توفر الإنترنت. ويمكن الضغط على `Check updates` في الشريط العلوي للفحص اليدوي. عند وجود إصدار أحدث:

1. يعرض التطبيق رقم الإصدار وملاحظاته ويطلب موافقة المستخدم.
2. ينزّل `WinPilot-USB-Update.zip` عبر HTTPS ويتحقق من SHA-256 المنشور في الإصدار.
3. يشغّل نسخة مؤقتة من `WinPilot-Updater.exe` ثم يغلق التطبيق.
4. يأخذ المحدث نسخة احتياطية مؤقتة، يستبدل الملفات، ويعيد التشغيل. عند أي فشل يستعيد الملفات السابقة.

لا تحذف حزمة التحديث `Apps` أو `Ads` أو `info.txt`. ولا تستبدل منها إلا ملفات موجودة صراحة داخل ZIP. لذلك تحفظ البرامج والإعلانات وبيانات التواصل المحلية.

النسخ `1.0` وما قبلها لا تحتوي على المحدث، وتحتاج استبدالًا يدويًا لمرة واحدة بملفي `WinPilot-USB.exe` و`WinPilot-Updater.exe` من الإصدار `1.1.0`.

### إنشاء إصدار قابل للتحديث

أنشئ tag مثل `v1.1.1`. يبني GitHub Actions التطبيق والمحدث وينشر الملفات التالية:

- `WinPilot-USB-Update.zip`
- `WinPilot-USB-Update.sha256`
- `WinPilot-USB.exe`
- `WinPilot-Updater.exe`
- `SHA256SUMS.txt`

الحزمة الآلية تشمل التطبيق والمحدث والسكربتات والأصول، ولا تشمل مجلدات المستخدم `Apps` و`Ads` ولا `info.txt`. لإضافة برنامج جديد، يجب تضمين مثبت البرنامج المرخص داخل مسار `Apps` في حزمة تحديث مخصصة، إلى جانب تعريفه الجديد في `scripts/local-apps.json`.

لإنشاء حزمة محلية وإضافة مثبتات محددة حسب `Id` من manifest:

```powershell
.\scripts\New-UpdatePackage.ps1 -AppIds "program-id-1","program-id-2"
```

تظهر الحزمة والبصمة داخل `release-local`. ارفعهما إلى GitHub Release بالاسمين الثابتين. لا تنشر مثبتًا قبل التأكد من حق إعادة توزيعه وحجم GitHub Release المسموح.

## التحديث اليدوي

1. أغلق Weeshi USB Installer على الجهاز.
2. احتفظ بنسخة احتياطية من مجلد `Apps` و`Ads` وملف `info.txt`.
3. استبدل `WinPilot-USB.exe` بالنسخة الجديدة.
4. استبدل مجلد `scripts` و`assets` إذا نصت ملاحظات الإصدار على ذلك.
5. لا تحذف مجلد `Apps`؛ فهو يحتوي على مثبتات البرامج المحلية.
6. انسخ `WinPilot-Updater.exe` بجانب التطبيق، ثم شغّل النسخة الجديدة وتحقق من رقم الإصدار الظاهر.
7. بعد استبدال أي مثبت، شغّل `scripts\Update-InstallerHashes.ps1` ثم راجع قيم `SHA256` قبل التوزيع.

لإعادة بناء التطبيق استخدم `scripts\Build-WinPilot.ps1 -Clean` من مجلد المشروع، ثم اختبر الملف التنفيذي ووقّعه قبل التوزيع.

## إضافة برنامج جديد

ضع ملف التثبيت داخل `Apps`، ثم أضف تعريفه إلى `scripts\\local-apps.json` مع اسم فريد ونمط ملف ومعاملات التثبيت الصامت الصحيحة. اختبر أولاً باستخدام بيئة اختبار منفصلة.

## تحديث الإعلانات

استبدل ملفات الصور داخل `Ads` مع الإبقاء على أسماء الملفات المطلوبة مثل `dsa1.xxx`. يجب أن تكون الملفات صوراً صحيحة حتى لو كان الامتداد غير معتاد.

## التراجع

إذا ظهرت مشكلة، أغلق التطبيق وأعد النسخة السابقة من `WinPilot-USB.exe` وملفات `scripts`. لا تستبدل مجلد `Apps` إلا إذا كان التحديث يتضمن ملفات تثبيت جديدة.
