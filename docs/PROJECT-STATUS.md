# حالة مشروع WinPilot-USB

## المزايا الحالية

- تشغيل محمول من USB.
- تثبيت برامج EXE وMSI بصمت حسب `local-apps.json`.
- تثبيت MSIXBundle عبر `Add-AppxPackage` مع رسالة خطأ واضحة.
- اختيار برنامج واحد أو عدة برامج أو كل البرامج المكتشفة.
- وضع `-List` لعرض المثبتات المكتشفة.
- وضع `-DryRun` لمعاينة الأوامر دون تنفيذها.
- سجلات تثبيت في `scripts/logs`.
- بطاقة Office لفتح ISO، وبطاقة Drivers لتشغيل مثبت SDI.
- إدارة Windows Update مع حفظ الحالة والاستعادة.
- بطاقة مستقلة لتفعيل Windows وOffice تشغّل `MAS_AIO.cmd` كمسؤول.
- بطاقتان منفصلتان لإيقاف وتشغيل Windows Update.
- أربعة أزرار تواصل تفاعلية أسفل أرقام الهاتف.
- شبكة أدوات 2×3 داخل حاوية موحدة، بخلايا متساوية للبطاقات وبيانات التواصل.
- واجهة Windows Forms عربية/إنجليزية وإعلانات محلية.
- تحديث ذاتي من GitHub Releases مع فحص تلقائي ويدوي، تقدم تنزيل، SHA-256، محدث مستقل، إعادة تشغيل وrollback.
- نقل اختيارات البرامج من نسخة الويب إلى Windows عبر JSON أو بروتوكول `winpilot://`.
- اكتشاف البرامج المثبتة وإصداراتها وفحص Windows والبنية والمساحة قبل التثبيت.
- إلغاء واستكمال قائمة التثبيت، وإعادة المحاولة أو التخطي، وتقارير جلسة HTML وJSON.

## الإصلاحات المنفذة

1. استبدال المسار الثابت بمسار ديناميكي مشتق من موقع المشروع.
2. منع البحث من اعتبار ملفات السكربتات مثبتات.
3. إصلاح عمل `-List` و`-DryRun` من داخل مجلد المشروع.
4. إضافة التحقق من SHA-256 قبل تشغيل المثبتات.
5. تحسين التعامل مع MSIX والفشل وإرجاع Exit Codes.
6. إضافة تأكيد وتحذير قبل تعطيل Windows Update.
7. حفظ حالة Registry والخدمات للاستعادة.
8. إضافة إصدار Windows وبيانات الشركة داخل الملف التنفيذي.
9. إضافة مشروع بناء موثق قابل لإعادة الإنتاج.
10. إضافة مشروع `WinPilot-Updater` وحماية من ZIP traversal والحفاظ على ملفات المستخدم أثناء التحديث.

## نتائج التحقق

- بناء .NET: ناجح دون أخطاء.
- تحليل PowerShell: صفر أخطاء نحوية.
- `-List`: ناجح ويكتشف البرامج المحلية.
- `-DryRun`: ناجح ويتحقق من hashes.
- عدد المثبتات ذات SHA-256: `18/18`.
- تشغيل الملف التنفيذي: ناجح في اختبار التشغيل المحلي.
- اختبار المحدث: نجح استبدال الملفات، الحفاظ على `info.txt`، rollback عند فشل النسخ، ورفض ZIP traversal.

## ما لم يكتمل بعد

- التوقيع الموثوق لم يُنفذ بعد لعدم توفر شهادة Code Signing.
- قبول SignPath Foundation قرار خارجي يتطلب تقديم المشروع ومراجعته.
- اختبار التثبيت الفعلي لكل برنامج يحتاج أجهزة/آلات افتراضية Windows 10 وWindows 11.
- مجلد `Apps` غير منشور في GitHub؛ يجب توزيعه محليًا مع مراعاة تراخيص كل برنامج.

## آخر البرامج المضافة

- Microsoft Visual C++ Redistributable x64/x86 — مثبتان صامتان وSHA-256 متحقق.
- .NET Desktop Runtime 9 x64/x86 — مثبتان صامتان وSHA-256 متحقق.
- CrystalDiskInfo 9.9.5 — تثبيت Inno Setup صامت وSHA-256 متحقق.
- Google Drive for desktop — أضيف إلى manifest، ونجح `DryRun` مع SHA-256 للملف المحلي.
- Kaspersky Virus Removal Tool 20.0.10.0 — أضيف إلى manifest، وتم التحقق من SHA-256 ونجح `DryRun`.
- Google app for desktop — لم يعد ضمن قائمة التثبيت لعدم توفر مثبت محلي ثابت.

## العناصر المستبعدة

- Kaspersky Antivirus Offline: أزيل من التطبيق لأنه لا يملك أمر تثبيت صامت موثقًا في الحزمة.
- Google app for desktop: أزيل من التطبيق لعدم توفر ملف مثبت محلي ثابت يمكن التحقق من SHA-256 له.
