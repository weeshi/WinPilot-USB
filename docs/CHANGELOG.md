# Weeshi USB Installer — سجل الإصدارات

## 1.0 — 2026-11-08

- اعتماد اسم Weeshi USB Installer.
- إضافة شعار التطبيق في الترويسة وأيقونة Windows.
- إضافة قائمة برامج محلية مع أرقام الإصدارات وخانات اختيار.
- إضافة زر أخضر أساسي باسم `Install silently`.
- إضافة رسائل التثبيت والفشل والمتابعة أو الإلغاء.
- دعم تثبيت البرامج من الفلاش بدون اتصال بالإنترنت.
- إضافة بطاقة Office لفتح `Apps\\office.iso` بالطريقة العادية.
- إضافة بطاقة Drivers لمجلد `Apps\\SDI_RUS`.
- إضافة سكربت إدارة Windows Update مع خيار الاستعادة.
- إضافة إعلانات متحركة تتغير كل 3 ثوانٍ.
- إضافة تحميل بيانات التواصل من `info.txt`.
- إضافة رقم الإصدار `Version 1.0` داخل الواجهة.
- تحسين قياسات النافذة لتناسب شاشات 1366×768 تقريباً.
- إعادة ترتيب الواجهة وفق تصميم Stitch: شريط علوي، لوحة أدوات يساراً، قائمة التطبيقات يميناً، وشريط حالة سفلي.
- اعتماد لوحة ألوان navy/cyan مع بطاقات وأقسام أكثر وضوحاً.
