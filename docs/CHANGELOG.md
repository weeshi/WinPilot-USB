# Weeshi USB Installer — سجل الإصدارات

## Unreleased — تحسينات ما بعد 1.0

### البناء والإصدار

- إضافة `WinPilot-USB.csproj` لإعادة بناء التطبيق بإصدار `1.0.0.0` وبيانات منتج وشركة واضحة.
- إضافة `scripts/Build-WinPilot.ps1` للبناء والتنظيف والنسخ إلى جذر الحزمة.
- إضافة دعم توقيع Authenticode اختياري عبر بصمة شهادة و`signtool.exe`.
- إنشاء مستودع GitHub عام وإضافة ترخيص MIT.
- إضافة GitHub Actions للبناء على `windows-latest` وإنشاء GitHub Release عند استخدام Tags مثل `v1.0.1`.
- تجهيز مرحلة SignPath Foundation بحيث لا تعمل إلا بعد قبول المشروع وإضافة الأسرار والمتغيرات المطلوبة.
- استبعاد المثبتات التجارية الكبيرة من GitHub مع إبقاء مجلد `Apps` للحزمة المحلية.

### التحقق والأمان

- إضافة SHA-256 نهائي لكل المثبتات الـ18 الموجودة في `Apps` إلى `scripts/local-apps.json`.
- إضافة تحقق SHA-256 قبل تشغيل المثبت عند وجود قيمة hash.
- إضافة تحذير عند غياب hash بدل اعتبار الملف موثوقًا تلقائيًا.
- تحسين رسالة فشل MSIX لتوضيح احتمال الحاجة إلى Dependencies أو إصدار Windows أحدث.
- إضافة تأكيد كتابي `DISABLE` قبل تعطيل Windows Update.
- حفظ حالة الخدمات وسياسة Registry قبل التعطيل، مع إزالة ملف النسخ الاحتياطي عند الاستعادة.
- إصلاح المسارات الثابتة `D:\App\WinPilot` وجعل السكربت يكتشف جذر المشروع تلقائيًا.
- إصلاح استثناء المسار بحيث يتم البحث في `Apps` ولا يتم اعتبار ملفات `scripts` مثبتات.

### التوثيق والتوافق

- تحديث أدلة الاستخدام والتحديث والبناء.
- توثيق أن التطبيق x86 ويستهدف Windows 10 وWindows 11 عبر WoW64.
- توثيق أن التوقيع العام لم يتم اعتماده بعد، وأن الشهادة الذاتية لا تعادل شهادة موثوقة.

### حزمة البرامج الإضافية

- إضافة Microsoft Visual C++ Redistributable 2015+ لكل من x64 وx86.
- إضافة .NET Desktop Runtime 9 لكل من x64 وx86.
- إضافة CrystalDiskInfo 9.9.5 للفحص الصحي للأقراص.
- إضافة Google Drive for desktop إلى manifest ومعامل `--silent` الخاص بالمثبت المتاح محليًا.
- إضافة عنصر Google app for desktop باسم Google Search Desktop كعنصر يدوي مؤقت؛ لم يتم تضمين مثبت لأن Google لا يوفر رابطًا ثابتًا موثقًا للملف التنفيذي.
- التحقق من SHA-256 للبرامج الجديدة القابلة للتثبيت واختبارها عبر `DryRun`.

### إزالة عناصر غير قابلة للتثبيت الصامت

- إزالة Kaspersky Antivirus Offline من manifest والحزمة لأنه كان معرفًا كتثبيت يدوي وليس مثبتًا صامتًا موثقًا.
- إزالة Google app for desktop من قائمة التثبيت لأنه لم يتوفر له مثبت محلي ثابت قابل للتحقق.
